Navegación por voz

  • «Inicio», «catálogo» o «carrito»
  • «Iniciar sesión» o «mi cuenta»
  • «Subir», «bajar» o «volver arriba»
  • «Más información» para abrir una ficha
  • «Controles» para volver a la navegación
  • «Cerrar» para cerrar una ventana
  • «Detener voz» para apagar el micrófono

El navegador puede procesar la voz en línea. El micrófono solo se activa al pulsar Activar voz y se apaga al cambiar de pestaña. Los comandos no realizan cobros.

Este navegador no admite reconocimiento de voz. Prueba en un navegador compatible, como Chrome, o usa el teclado.
